# CIC-IDS2017 Dataset Import Guide

## Dataset Provenance

CIC-IDS2017 is a publicly available intrusion detection benchmark produced by the
Canadian Institute for Cybersecurity (CIC) at the University of New Brunswick.

**Reference:**
> Sharafaldin, I., Habibi Lashkari, A., Ghorbani, A. (2018).
> "Toward Generating a New Intrusion Detection Dataset and Intrusion Traffic Characterization."
> Proceedings of the 4th International Conference on Information Systems Security and Privacy (ICISSP).

**Official URL:** https://www.unb.ca/cic/datasets/ids-2017.html

---

## Obtaining the Dataset

1. Visit https://www.unb.ca/cic/datasets/ids-2017.html
2. Register or use the download link provided on the page.
3. Download the **MachineLearningCVE** archive (~500 MB).
4. The archive contains 8 daily CSV files generated by CICFlowMeter.

## Loading the Dataset

```python
from backend.ingestion.cicids_loader import load_cicids2017

events, stats = load_cicids2017(
    "datasets/cicids2017/Tuesday-WorkingHours.pcap_ISCX.csv",
    max_rows=5000,          # Optional: limit rows for development
    deduplicate=True,       # Recommended: remove duplicate flows
    internal_ip_prefix="192.168.",  # CIC-IDS2017 internal network prefix
)

print(f"Loaded: {stats['valid_events_loaded']} events")
print(f"Labels: {stats['label_distribution']}")
print(f"Unmapped: {stats['unmapped_labels']}")
```

## Known Dataset Issues

| Issue | Impact | Mitigation in Loader |
|-------|--------|----------------------|
| Inf values in `Flow Bytes/s`, `Flow Packets/s` | Causes NaN in feature extraction | Replaced with NaN, then 0.0 |
| Negative flow values (CICFlowMeter overflow bug) | Invalid features | Set to NaN |
| ~1% duplicate rows | Inflates training counts | `deduplicate=True` removes them |
| Label casing inconsistencies | Missed mappings | Normalized to lowercase |
| Missing timestamps in some files | Incorrect temporal ordering | Sequential fallback timestamps assigned |
| `Flow Duration` in microseconds | Incorrect duration_ms | Divided by 1000 |
| 'Web Attack – Brute Force' with em dash | Missed by string match | Explicit replacement applied |

## Label Mapping

CIC-IDS2017 labels are normalized to AEGIS canonical classes:

| CIC-IDS2017 Label | AEGIS Canonical Class |
|-------------------|-----------------------|
| BENIGN | benign |
| FTP-Patator | brute_force |
| SSH-Patator | brute_force |
| Web Attack – Brute Force | brute_force |
| Web Attack – XSS | brute_force |
| Web Attack – SQL Injection | brute_force |
| PortScan | lateral_movement |
| Infiltration | lateral_movement |
| Bot | c2_beaconing |
| DDoS | c2_beaconing |
| DoS Hulk | c2_beaconing |
| DoS GoldenEye | c2_beaconing |
| DoS slowhttptest | c2_beaconing |
| DoS Slowloris | c2_beaconing |
| Heartbleed | data_exfiltration |

**Note:** These mappings are approximate. DoS/DDoS attacks are mapped to `c2_beaconing`
as the closest AEGIS category (command-and-control controlled distributed attack).
This may not be a perfect semantic match but enables comparison on the same label space.

## Important Warnings

1. **Do not commit CIC-IDS2017 files to git.** File sizes exceed 100 MB per file.
2. **Keep CIC-IDS2017 results separate** from synthetic dataset results.
   Never report them as the same experiment.
3. **Generalization is limited.** CIC-IDS2017 was generated in a controlled lab environment
   with specific tools (IXIA PerfectStorm). Real-world traffic may differ significantly.
4. **Feature mismatch risk.** AEGIS features are derived from flow statistics plus
   behavioral baselines. If the CIC-IDS2017 file lacks `Source IP` columns,
   entity resolution falls back to `"unknown_src"`.
